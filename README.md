# Documentation

Documentation for 0SFS: how to run and build the simulator, aircraft and asset notes, proposals, and release checklists.

The monolith split is published. [repository-split.md](repository-split.md) is where things stand and what is left. [parity-checklist.md](parity-checklist.md) is the human check against the old app.

[Choosing the useful peaks of realism and cost](realism-cost.md) explains why we compare multiple simulation implementations and how we retain the choices that justify their resource and maintenance costs.
